# Comparison of multi-agent workflow architectures with LangChain

This project compares multi-agent interactive workflows across a few architectural approaches.

- Conversation manager with sub-agent
- Handoffs (Single agent with state tracking to update agent configuration. Tools drive state/handoff)
- Single agent

We'll compare these approaches across:

- Latency
- Token efficiency (cost)
- Output quality (a few LLM Judges)
- Ease of evaluating

May update this later with more comparison dimensions.
